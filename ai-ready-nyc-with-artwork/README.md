# AI Ready NYC

A responsive three-day AI literacy programme website with original scalable vector artwork inspired by the approved concept. Built with Vite and vanilla JavaScript, using Material-inspired interaction and Google's four-colour palette.

## Run

```bash
npm install
npm run dev
npm run build
```

## Notes

- The illustrations in `/assets` are original SVG vectors, transparent on the hero and resolution-independent (no pixelation at desktop size).
- BBC Pathfinder linking is configured through `VITE_PATHFINDER_URL`; replace the placeholder URL with the confirmed programme route.
- Application links are demonstrative until registration opens. Dashboard progress is stored in `localStorage` in the current browser; this is a frontend prototype, not a real account backend.
- Partnership acknowledgements are descriptive text, not a claim of an official Google / BBC website. Confirm logo/brand usage before public launch.
